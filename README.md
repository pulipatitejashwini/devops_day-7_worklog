# Task 7: Environment Variables & PATH (Linux)           

## Overview
This task focuses on understanding Linux environment variables and the PATH variable, which are widely used in DevOps for application configuration and runtime management.   
I practiced creating shell and environment variables, modifying PATH, making configurations persistent, and validating variable behavior across shell sessions.            

## Tools Used
- **Primary:** Bash                
- **OS:** Linux (Ubuntu)             

## Objectives
- Understand environment variables in Linux          
- Differentiate between shell-local and exported variables           
- Modify and manage the PATH variable            
- Make environment variables persistent across sessions           

## What I Did
- Viewed existing environment variables using `env` and `printenv`           
- Created shell-local variables and verified their scope            
- Exported variables to make them available to child processes             
- Validated the difference between exported and non-exported variables using shell scripts          
- Modified the PATH variable to include custom directories            
- Made environment variables persistent by updating `.bashrc`            
- Reloaded configurations using `source ~/.bashrc`          
- Tested persistence across new shell sessions              
- Debugged PATH-related issues                         

## Deliverables
- Environment variable configuration screenshots              
- PATH modification proof             
- `.bashrc` configuration file updates               
- Variable persistence validation outputs     

## Final Outcome
Successfully configured and managed Linux environment variables and PATH, gaining hands-on experience in runtime configuration and system-level setup commonly used in DevOps environments.
